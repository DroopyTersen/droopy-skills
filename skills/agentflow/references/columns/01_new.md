# New

New captures work for consideration. A raw idea, one-line note, or deeply investigated bug is equally valid; no template, type, priority, acceptance-criteria threshold, or research pass is required to capture Andrew's request.

- Create an item only when Andrew asks or approves its creation. Use his supplied detail and only the provider's necessary fields.
- An agent-suggested item should include decent evidence, a concrete problem or opportunity, and proposed acceptance criteria so Andrew can decide whether to create it.
- Create in New by default. Move to Approved only when Andrew explicitly directs that status change; deciding to create a card is not approval to start work.
- Check for an obvious duplicate and link useful existing evidence. Do not impose a mandatory investigation before capturing an idea.

No embedded history table or metadata ceremony is needed. See [Approved](01b_approved.md) when Andrew approves the work.
